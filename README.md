# 주술 문제 페이지 (GitHub Pages)

내 SQLD / ADSP 암기용 문제 HTML을 GitHub Pages로 바로 띄울 수 있게 기본 구성을 넣었습니다.

## 사용 방법

1. 이 저장소 루트의 `index.html` 내용을 원하는 문제/주술 HTML로 수정합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (또는 현재 기본 브랜치), `/ (root)`
4. 저장 후 잠시 기다리면 아래 주소로 접속할 수 있습니다.
   - `https://vicefan.github.io/-/`

> 저장소 이름이 `-` 이라 URL 경로도 `/-/` 형태로 잡힙니다.
